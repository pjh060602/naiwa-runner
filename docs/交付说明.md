# 奶蛙快跑 · 交付说明（MVP）

## 怎么玩

- 电脑：http://localhost:5180/
- 手机（同一 WiFi）：http://192.168.3.8:5180/

若服务没起：`cd game && npm run build && npx vite preview --port 5180 --host`

| 键 | 动作 |
|---|---|
| ← → / A D | 换道 |
| ↑ / W / 空格 | 跳 |
| ↓ 轻点 | 普通滑铲（0.5s） |
| ↓ 按住 | 肚皮滑行（≤1.4s，能钻半高障碍，松手弹跳） |
| R / 点屏幕 | 重开（每局都会重新播开场） |

## 调试参数

| 参数 | 作用 |
|---|---|
| `?seed=N` | 固定关卡 |
| `?bot=1` | 自动驾驶长跑 |
| `?chaser=N` | 直接设定追兵距离 |
| `?gallery=<kind>` | 只看某一种障碍（stool/cart/awning/pole/cat） |
| `?stage=caught&t=line\|laugh` | 定格在结局演出的某一段 |
| `?cam=side` | 侧向机位（看风景/验收场景用） |

## 技术栈与结构

Vite + TypeScript + three.js，纯静态无后端。

- `game/src/core/` — 循环、输入、配置、调色板
- `game/src/world/` — 公园场景（park/track/prefabs/glow/obstacles/collectibles/chaser/stage）
- `game/src/player/` — 车道状态机、跳跃/滑铲物理、碰撞
- `game/src/character/` — 奶蛙与袋鼠的纸片人模块（billboard）
- `game/src/audio/` — AudioBus、演出音频调度
- `game/public/models/` — 角色贴图（正面/背面/捧腹大笑、袋鼠）
- `game/public/audio/` — 笑声与袋鼠台词

## 关键设计约束（改动时别破坏）

1. **角色是单面纸片人，正面朝 +Z**。相机必须待在 +Z 侧，追兵不能转 Y 去"面对"奶蛙，否则背面剔除会导致角色消失。
2. **贴图必须设 `colorSpace = SRGBColorSpace`**，否则颜色会被二次编码、整体发灰。
3. **碰撞盒尺寸是回归基准**，换美术皮不许动数值。`npm run verify:logic` 里有断言。
4. **演出由音频 ended 驱动**，不许用 setTimeout 硬编码时长——换音源会打乱节奏。
5. **caught-laugh 段相机不再重新绕位**（poseT 加 STAGE_ORBIT_SECONDS），否则换贴图时镜头会甩回背后。

## 验收命令

```
cd game
npx tsc --noEmit      # 类型
npm run verify:logic  # 34+ 条断言：碰撞矩阵 / 落地滑铲 / 演出时间轴 / CAUGHT 同框 / 相机

```

### 文件归属
- `game/src/world/props/**` — 道具几何体（由场景建模师维护）
- `game/src/world/backdrop/**` — 天空/海/远岛/云
- `game/src/world/park.ts` — 布局摆放（沙带区间 SAND_MIN..SAND_MAX、inset、spacing 节奏、接地暗斑）
- `game/src/world/obstacles.ts` — 碰撞（**碰撞盒与解法是回归基准，换皮不许动**）

### 场景这块踩过的坑（都在验收清单里了）
1. **世界必须跟着玩家走**：地面盘、天空穹顶、沙带、水面都要按玩家 x/z 跟随，否则跑远之后会看到世界边界、或穹顶被相机远平面切出巨大三角。
2. **视觉尺寸与碰撞盒可以不一致，但必须显式说明**（路标牌 0.86m > 0.4m 盒，牌子在 3–4.3m 高度不影响判定）。
3. **物件必须在游戏机位下验收**，不能只看孤立预览：贝壳平放时在俯角 3–13° 下几乎看不见，抬 34° 才读得出。
4. **预算贴顶就停止加细节**（棕榈 1154/1200、长椅 444/450）。
5. **报告必须附回读证据**（grep 行 + 内容），否则「报告」与「文件实际状态」的时间差会让验收方误判。
