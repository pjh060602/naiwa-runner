# 公园场景美术规范 v1

用户明确要求：场景要好看、精致。本文是验收基准，不达标就打回。

## 1. 时间与光照

| 项 | 值 |
|---|---|
| 时间设定 | 下午三点偏暖的日光（不是正午死白，也不是黄昏） |
| 主光 | 平行光，方向 (0.45, 0.82, 0.36)，色 #FFF3DC，强度 2.6 |
| 环境光 | 半球光，天空 #BFE3FF / 地面 #7FA05A，强度 1.1 |
| 补光 | 反方向弱平行光，色 #CFE6FF，强度 0.55（消死黑，不要用纯黑阴影） |
| 雾 | 色 #CFE8FF，近 90m 起、320m 全雾（远景化开，不要突然截断） |
| 阴影 | 允许不用实时阴影；但角色脚下必须有一层**贴地的柔和暗斑**（不是硬阴影） |

## 3. 构图（这条决定"好不好看"，不是细节）

1. **三层纵深**：近景（0–12m，大物件：树/花坛/长椅）→ 中景（12–60m，成排树列）→ 远景（60m+，树线剪影 + 天空）。
2. **禁止左右对称**：两侧的道具种类、间距、朝向必须不同步；用两个独立的循环流（左、右各一条），相位错开。
3. **疏密节奏**：每 3–4 个槽位要有一次"密集点"（两三个道具凑在一起），中间留空。均匀排布 = 廉价感。
4. **视线引导**：路两侧的树冠向中间收一点，形成"绿色甬道"，把视线压到路面上。
5. **不要贴脸**：任何道具都不要紧贴路的边缘，留 0.6m 以上的缓冲，否则速度感会变成"撞墙感"。

## 4. 道具清单（每个都必须有细节，不是方块）

| 道具 | 细节要求 |
|---|---|
| 乔木 | 树干**有锥度**（下粗上细）+ 树冠用 **3~5 个球体堆叠**（不是单球），加一个深色底冠做层次 |
| 灌木 | 2~3 个扁球堆叠，高度 0.6–1.2m |
| 花坛 | 砖边（一圈矮box）+ 内部花卉用**随机色点**（不是整块色） |
| 长椅 | 横板 3 条 + 两侧铁腿 + 靠背斜板，不能是一块长方体 |
| 路灯 | 细杆 + 顶部灯头（白天不发光），高度 4m |
| 垃圾桶 | 圆柱 + 顶部圈边 + 侧面色差 |
| 指示牌 | 杆 + 牌面（带一块浅色区域模拟文字），朝向道路内侧 |
| 台阶/矮墙 | 沿路布置，做高度变化 |

## 5. 地面

- 主路面：石板（浅灰），每 1.2m 一条**横向缝隙线**（用深色细条，不是贴图），缝色 #9E988A
- 路缘石：高 0.12m，色 #E2DCCB，两侧各一条
- 路边：草地，比路面**高 0.05m**，边缘要有一条不规则的过渡（不是直角切口）
- 树影/阳光斑：用**柔和的低透明度圆片**（opacity 0.10–0.16）贴地滚动，颜色偏暖白，不要用霓虹那套加法

## 6. 性能

draw call < 120（越少越好，目标 90 以内）、三角面 < 120k、桌机 60fps。
同类道具必须合并 InstancedMesh（每种 1 次 draw call），几何体在模块级只建一次、帧内零 new。
