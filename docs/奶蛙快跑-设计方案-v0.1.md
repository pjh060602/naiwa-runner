一款 3D 三车道跑酷，主角是奶蛙：你用大肚子贴地滑、用弹跳逃命，身后永远有个外卖袋鼠在追。

## 3. 核心体验

### 3.1 相机
- 背后第三人称：距角色 5.5 m、高 2.8 m、FOV 62
- 横向跟随延迟 0.12 s（换道时相机慢半拍，这是"跑酷味"的来源之一）
- 速度越高 FOV 越大（62 → 70），是廉价但有效的速度感

### 3.2 车道与操作
- 三条车道，车道宽 2.6 m，总宽 7.8 m
- 换道：0.16 s 缓动，不可穿透中间车道（真·位移，不是瞬移）
- 跳跃：重力 32 m/s²，初速 9 m/s → 峰高 1.27 m、滞空 0.56 s
- 滑铲：0.5 s，碰撞盒高度 1.6 m → 0.6 m
- 键盘：← → / A D 换道，↑ / W / Space 跳，↓ / S 滑铲
- 触屏：上下左右滑动，滑动距离阈值 30 px

### 3.3 记忆点一：肚皮滑铲
普通滑铲只管 0.5 s。奶蛙的滑铲是**可长按的肚皮滑行**：
- 长按 ↓ 进入滑行，最长 1.4 s，速度 ×1.1
- 滑行中碰撞盒高 0.5 m，能钻过半高障碍（灯串、遮阳棚、栏杆）
- 松手时肚皮把身体弹起 0.8 m 的小跳，可衔接跳跃
- 代价：滑行中换道延迟 +40%（转向变笨），且不能连续二次滑铲（0.4 s 冷却）
- 这条机制让奶蛙的"大肚子"从造型变成玩法，是它和其他跑酷的根本区别

### 3.4 记忆点二：追杀者（替代血条）
- 一只**美团袋鼠形象**的追兵始终在身后 18 m（用户决定：直接用网络上已火的形象，不商用）
- 撞一次障碍拉近 4 m，被追上 = 结束（没有三条命，只有距离）
- 吃到加速道具拉开 6 m；速度越高它跟得越紧（压迫感随难度递增）
- 唯一安全区是"持续不撞"——这是把"跑得好"直接可视化的设计

### 3.5 难度曲线
- 速度 v(t) = 14 + (30 − 14) × (1 − e^(−t/60))，1 分钟到 26 m/s
- 障碍密度按距离分三档：0–400 m（稀）/ 400–900 m（中）/ 900 m+（密 + 双连障碍）
- 每 250 m 触发一次"节奏事件"（连续 3 个同类障碍，逼你连续同一操作）

## 4. 内容清单（v0.1 夜市场景）

障碍 5 种：
| 障碍 | 尺寸特征 | 应对 |
|---|---|---|
| 塑料凳 | 低矮 0.4 m | 跳 |
| 夜宵推车 | 高 1.8 m 占 1 车道 | 换道 |
| 遮阳棚 / 灯串 | 半高 1.2 m 悬空 | 滑铲（或肚皮滑行穿过） |
| 电线杆 | 窄 0.3 m | 换道 |
| 流浪猫 / 醉汉 | 会在车道间小幅移动 | 预判换道 |

收集物 1 种：奶瓶。攒 20 瓶 = 一次"加速奔跑"（同时拉开追杀者 6 m）。

## 5. 美术规范

- 风格：low-poly 程序化建模 + 纯色 PBR（MeshStandardMaterial），原则上**不用贴图**，只靠形体 + 顶点色，保证 AI 可全流程自产且风格统一
- 奶蛙比例：身高 1.5 m；头占身高约 40%；躯干为一颗大水滴/胶囊，肚皮为正面浅色椭球；眼睛两颗大球（深绿虹膜 + 极小高光黑瞳）；四肢为极短圆锥，无手指
- 配色（从参考图取）：主黄 #F5D93A ～ #F7C93E，肚皮 #F6EFD8，眼睛 #5E8F5A（绿）＋ #14170F（瞳）
- 动画只做 4 组（跑、跳、滑、撞），全部用 Group 层级旋转 + 缓动插值，不引外部骨骼文件
- 参考库：refs/naiwa/（已抓 77 张，见 §9 的噪声说明）

## 6. 技术方案

- Three.js + TypeScript + Vite；无后端，纯静态
- 模块分层：
  - core：固定步长游戏循环、输入（键盘/触屏统一成意图事件）
  - world：路板分块生成（对象池，3 块循环复用）、障碍生成器（按难度档位抽表）
  - player：车道状态机 + 竖直物理（抛物线积分）+ 碰撞盒 AABB
  - chase：追杀者距离模型
  - ui：分数/奶瓶/结算
- 性能预算：draw call < 120、三角面 < 120k、桌机 60 fps、中端手机 40 fps；必要时降渲染分辨率（devicePixelRatio 上限 2 → 1.5）
- 所有网格合并（InstancedMesh 用于路板/障碍重复件），避免逐帧创建

## 12. 追加决策（音效已定案）

奶蛙「捧腹大笑」音效已找到并经用户试听确认无误，作为游戏固定音效之一。

- 源文件：refs/audio/naiwa_laugh.mp3（14.83s 连续笑声，提取自「奶蛙挂件」应用素材 assets/audio/1.ogg）
- 切片：refs/audio/sfx/laugh_short.mp3（1.6s，局内高频）/ laugh_mid.mp3（4.0s，结算）/ laugh_full.mp3（14.8s，彩蛋）
- 用途：laugh_short 吃奶瓶与连续闪避成功；laugh_mid 结算页；laugh_full 阵亡嘲讽彩蛋
- 客观佐证：短时能量包络主调制频率 4.92 Hz（人类笑声节律区间 4–7 Hz），无静音间隙，-16 LUFS 归一
- 命名澄清：该梗在 B 站主流标题为「奶龙捧腹大笑」，原版时长 00:15，与本素材 14.83s 吻合；「奶蛙」为同源变体叫法。后续检索应同时用「奶龙」关键词。

## 13. 音效口径修正（用户要求）

用户明确：捧腹大笑音效不要用太多，只在关键时刻或胜利/失败时使用。

| 触发点 | 用哪段 | 说明 |
|---|---|---|
| 被追上 / 阵亡 | laugh_short（1.6s） | 用短的，不用 4 秒版，避免每死一次听 4 秒 |
| 打破个人最高纪录 / 结算胜利 | laugh_mid（4.0s） | |
| 里程碑（每 500m） | laugh_short，带冷却 | |
| 全局彩蛋（首次 1500m） | laugh_full（14.8s） | 全程最多一次，触发后本局不再播任何笑声 |
| 吃奶瓶 / 闪避成功 / 连击 | **禁止使用笑声** | 改用短促合成音（叮/噗/嗒） |

硬性限制：单局笑声累计 ≤ 3 次；两次笑声间隔 ≥ 20 秒；重开打断正在播放的笑声；笑声独占一个音频通道。

## 14. 追兵机制定案（用户选择：撞击不立即死）

原设计 §3.4 的「追杀者替代血条」正式落地，规则：

| 项 | 数值 |
|---|---|
| 追兵初始距离 | 身后 18 m |
| 撞到障碍 | **不死**，玩家踉跄（速度 ×0.6 持续 0.35 s），追兵拉近 4 m |
| 追兵自然拉开 | 每秒 +0.35 m，上限回到 18 m |
| 被追上 | 距离 ≤ 0 → 本局结束，进结算页 |
| 吃奶瓶加速 | 额外拉开 6 m |
| HUD | 常驻「追兵距离」条；< 6 m 时条变红并闪烁 |

**可视性说明**：第三人称背后视角下，追兵正常在相机后方，看不见。因此追兵模型只在距离 < 6 m 时可见（从相机边缘逼近），其余时间靠 HUD 条传达压力；死亡瞬间由追兵扑上来收尾。

**追兵形象**：美团袋鼠（用户已确认不商用，直接用网络形象）。

## 15. 开场对峙过场（用户新增需求）

游戏正式开始前播一段约 4.6 秒的过场：奶蛙与追兵对峙、产生冲突，然后开跑，游戏正式开始。

| 时间 | 内容 |
|---|---|
| 0.0–0.5s | 黑场淡入，镜头横移至「正面 3/4 机位」，同时展示双方全身 |
| 0.5–2.2s | 对峙：奶蛙播 taunt（叉腰/拍肚子/得意摇晃），袋鼠播 angry（前倾、跺脚、甩尾） |
| 2.2–2.6s | 袋鼠 lunge 前扑 + 奶蛙 startle 惊吓，配镜头微抖 |
| 2.6–3.6s | 奶蛙转身开跑，镜头从正面连续摇到背后跟随 |
| 3.6–4.6s | 追兵从 4m 平滑拉回 18m，HUD 距离条同步；4.6s 进入 RUNNING，距离与计时从 0 开始 |

硬要求：
- 任意键/点击/触摸可跳过，跳过后状态必须干净（追兵 18m、计时 0、无残留动画）
- 过场期间不计算距离、不生成障碍、除跳过外忽略输入
- 运镜必须连续，不得切镜头
- 第一个障碍在过场结束 2 秒后才出现
- 过场内不使用笑声素材

新增角色状态：奶蛙 taunt / startle；袋鼠 angry / lunge。
