# 海滨公园场景规范 v1

用户要求：改成海滨公园，**树要大幅减少**。

## 1. 总基调
开阔、明亮、有风感和海平线。**核心是"空"**：现在的问题不是缺少东西，是树太多把视野堵死了。

## 2. 树：减到现在的 1/4
- **只保留一种树：棕榈**，且只在**人行道内侧**种一排，间距 18–26m（稀疏），不要两侧都种
- 取消：乔木成排、灌木篱、灌木球、花坛
- 棕榈结构：细杆（0.14m，有轻微弯曲）+ 顶部 6–8 片放射状叶（长条三角面，向前下方垂）

## 3. 新增（海滨元素）

| 元素 | 说明 |
|---|---|
| **海** | 左侧或右侧一整片水面，色 #4FA3C7 → 远处 #2E7FA8，水面有横向波纹带（低对比、滚动） |
| **沙滩** | 海与步道之间的沙带，色 #E8D9B5，边缘不规则 |
| **海堤栏杆** | 木色或白色细栏杆，沿步道靠海一侧连续，高 1.0m，柱间距 2.4m |
| **木栈道段** | 步道可以有一条木色段落（每 60–80m 交替一次），打破单调 |
| **海风草** | 沙滩边缘的丛状草，色 #A8B86A，成片但低矮（0.3–0.5m）|
| **遮阳伞 + 躺椅** | 沙滩上零星 2–3 组，间距很大，不要成排 |
| **救生塔** | 远景一个就够，红白条纹，作为地标 |
| **海鸥** | 空中 3–5 只，缓慢盘旋（纯视觉，不参与碰撞） |
| **远岛剪影** | 地平线处一到两个深色岛影 |

## 4. 地面
- 步道：浅色花岗岩石板 #D5CDBB，缝极淡 #C8C0AE（现在的对比度就行）
- 步道靠海一侧：栏杆 + 沙
- 步道内侧：草地 #7FA85C，但面积比现在小
- 所有落地物保留接地暗斑

## 5. 光照与天空
- 主光 #FFF6E0、强度 2.9、方向 (0.35, 0.75, 0.45)（午后偏侧）
- 半球光：#CFE9FF / #E8D9B5，强度 1.2
- 雾：#DCEFFF，40 → 280（海面要能看清远，雾别太浓）
- 天空：天顶 #4FA8DE → 地平 #DCEFFF，比现在更蓝更透

## 6. 障碍换皮（碰撞盒一个数不动）
| 原 kind | 新形象 | 解法 |
|---|---|---|
| stool | **沙滩椅**（低矮，0.4m） | jump |
| cart | **救生塔底座 / 系船柱**（1.8m 占一车道） | lane |
| awning | **海滨遮阳棚横杆**（1.2m 悬空） | slide |
| pole | **路标立柱** | lane |
| cat | **海鸥（地面走动的）** | jump |

## 7. 性能
draw call < 120、三角面 < 120k、60fps。树少了应该更宽松。

## 8. 验收
四张截图（5s / 30s / 90s / 侧向），要求：
- 一眼能看出"海边"（能看见水或栏杆或沙滩）
- **树不占画面主体**，视野开阔
- 天空和海平线是画面的一部分，不是被树顶住
