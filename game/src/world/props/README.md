# 海滨道具 + 大背景（scene-artist）

每一种道具 = **一个已合并、带顶点色的 BufferGeometry**。场景里用 InstancedMesh 摆放，
所以每种只占 1 次 draw call：颜色全部烘在顶点色里，**没有任何贴图**。

- 预览：cd game && npm run dev → http://localhost:5173/props-preview.html
  - 一页看完所有道具 · 可旋转缩放 · 每件实时显示三角面数 / 预算
  - 单品：?item=palmGeometry ｜ 三视图海报（截图用）：?item=palmGeometry&sheet=1
  - 大背景：?backdrop=1（可加 &view=game|sea|islands|sky|wide）
  - **道具同框对照**：?backdrop=1&view=game&props=1（海 + 沙 + 棕榈 + 栏杆一起摆进游戏机位）
  - 三视图截图：shots/props/名字.png，总览 shots/props/all.png，背景 shots/props/backdrop-*.png，
    同框对照 shots/props/scene-game.png / scene-sea.png
- 构建器：props/build.ts 的 MeshBuilder（box / cyl / rod / beam / sphere / ellipsoid / torus / disc / quad / poly / sheet）
- 自检：cd game && npx tsc --noEmit

## 每件的部件构成与设计意图

### 棕榈 palmGeometry
- 主形：14 环 × 9 边主干（0.17→0.09，根部外扩，向 +x 前倾 0.52m），冠高 4.96 + 叶 0.92 = 5.88m
- 结构件：冠部叶鞘 · 冠心球 · 10 片叶（3 上扬 / 4 平展 / 3 下垂）· 每片叶有中脉凸脊
- 本轮复盘：叶面从 5 段加到 6 段、叶缘锯齿改成双频（27 / 51），侧看轮廓才有细齿而不是一条光滑弧
- 点缀：6 道环状叶痕 · 三颗椰果 + 果柄 · 2 片枯叶垂在冠下
- 意图：叶面正反都建（抬头看不会看穿），叶缘带锯齿起伏；冠的三种高度差让它像被海风吹过。

### 长椅 benchGeometry
- 主形：5 条座板（色差 0.88–1.08）+ 4 条靠背斜板（后倾 7°）
- 结构件：两侧铸铁腿（前后腿 + 座框梁 + 靠背立柱）· 前后横撑 · 靠背两端压条
- 点缀：弧形卷曲扁铁（本轮复盘：外卷 6 段 + 内收小卷 3 段，两笔卷曲是铸铁椅的辨识度）· 座板 4 颗 + 靠背 2 颗螺栓 · 连脚垫

### 遮阳伞 umbrellaGeometry
- 主形：8 瓣伞面（骨位 1.99、瓣中 1.90、沿口再折 0.05 布边）
- 结构件：两段木色中柱 + 接头箍 · 8 根伞骨 · 骨座 · 配重底座（两层盘 + 立管套）
- 点缀：顶尖圆帽 + 顶珠 · 伞里衬 · 2 根拉绳 + 打在沙里的木钉

### 救生塔 lifeguardGeometry
- 主形：4 支柱（2.06m）+ 平台 + 观察台（1.36×1.16×1.36）
- 结构件：两面 X 斜撑 · 平台栏杆（正前方给楼梯留口）· 5 级踏步楼梯 + 双斜梁 + 扶手立柱与斜扶手 · 四坡红屋顶
- 点缀：混凝土独立基础 · 红白条纹 · 三面玻璃 · 挂着的救生圈 · 旗杆与双面旗

### 栏杆段 railingSegmentGeometry
- 2.4m 段、高 1.0m、立柱径 0.07（球头 + 底座箍）；上扶手带压顶条 + 中/下横杆 + 5 根立杆 + 螺栓 + 收头端板
- 段与段之间用「起点一根立柱」拼成连续海堤栏杆

### 躺椅 loungerGeometry
- 主形：两根纵向主梁 + 5 条布面（色差）+ 4 条翻起的靠背板（后倾 35°）
- 结构件：四条外撇木腿 · 两道横向底撑 · 靠背两侧框条
- 点缀：铰接轴 · 靠背支撑臂 · 螺栓 · 连脚垫 · 卷起来的毛巾（躺椅才像被用过）

### 海风草 beachGrassGeometry
- 12 片两段折弯的薄叶（正反两面都建）+ 2 根抽穗草秆
- 叶色三档（浅绿/中绿/深绿）+ 干草色，丛才不像一把塑料片

### 沙滩椅障碍 benchObstacleGeometry（jump）
- 1.5 × 0.39 × 0.66：两侧折叠木架 + 6 条蓝白布面 + 压得很低的靠背（整体仍在 0.4m 内）
- 点缀：折叠毛巾 + 铆钉 + 接地暗斑；一眼看出「跨过去」
- 游戏机位复盘：布面提亮一档（深蓝 0x56a6c4 / 浅蓝白 0xd8f0f7）+ 靠背压一条浅色边 0xf4f1e4，
  15m 外不再像「地上的一道阴影」，代价 0 三角面

### 系船柱 bollardObstacleGeometry（lane）
- 加宽八边形基座（两级）+ 锥形白柱身 + 两道海军蓝箍 + 圆帽
- 点缀：缠绕的缆绳 + 垂下的绳头；1.8m 高，只能换道

### 遮阳棚横杆 awningBarGeometry（slide）
- 两根白柱只做到 1.2m（碰撞盒 minY=1.2，柱子做高了会穿帮）
- 蓝白相间横梁正压在 1.19–1.31m，全长 2.44m，两端比柱子各长出 0.17m
- 横梁上方条纹篷布 + 前沿荷叶垂边 + 尾端横杆和斜撑：抬眼看就是「低头钻」
- 游戏机位复盘：篷布蓝加深一档（0x2f6b8a）+ 前沿垂边统一压成深靛 0x2f4f6b，
  20m 外不再整块退成灰板；横梁的蓝保持不变（它才是 slide 的判定提示）

### 路标立柱 signpostGeometry（lane）
- 4.68m 立柱 + 混凝土底座 + 柱顶帽；三块牌集中在 3.0–4.3m（蓝方向牌 / 白距离牌 / 红边警示牌）
- 点缀：两处抱箍 + 螺栓
- 游戏机位复盘：三块牌放大到 1.1 / 0.86 / 0.56m 宽，30m 外不再只剩一根杆；
  牌面在 3.0–4.3m（玩家头顶以上），与 0.4m 碰撞盒不会相交，lane 判定不受影响

### 海鸥 gullGeometry（jump）— 第二次打磨，468 / 500 tris
- 姿态「受惊起飞前半拍」：身体前倾 9°、颈子拉长、头微抬并侧偏 19°（转头是最强的「活物」信号），
  双翼半张 —— 上臂段向后外展、前臂段折向上、腕部 4 根初级飞羽向后上方散开
- 结构：身体椭球按纬度分两段上色（下腹白 / 上背深灰）+ 颈（圆杆）+ 头（球）+ 上下喙两片（中间留缝＝微张嘴）
  + 肩部覆羽（盖住肩缝）+ 尾羽三片扇形 + 大腿 / 胫骨 / 蹼足
- 明度分层：背深灰 0x8b949c / 翼中灰 0xb9c2c8 / 翼尖近黑 0x353b42 / 腹白 0xf7f7f3 / 喙橙黄 0xe8a93b / 腿粉橙 0xe0906a
- 眼睛 = 浅色一圈 + 中间黑点（两片薄板），8m 外也能看出「有神」
- 所有薄板（翼段 / 飞羽 / 尾羽 / 蹼足）都走 build.ts 的 panel 助手：给 4 个角点 + 厚度向量，
  法线按几何自动朝外。第一次打磨踩过「薄面靠 up/down 判朝向 → 从上方看整片发黑」的坑，panel 就是为根治它

### 高门架 barrierGeometry()（slide 专用，工厂函数）—— 海滨栈道木门架
- 尺寸：宽 2.60 / 深 0.31 / 高 2.60，原点在地面中心，正面朝 +z；**中央净跨 |x| < 1.0 里没有任何低于 1.05m 的实体**
- 立柱：漂流木质感——三段带锥度（0.115→0.088）和微弯，三段不同风化色（tint 0.90 / 1.00 / 1.02），柱身 8 边
- 柱脚：一圈沙堆（0xE8D9B5，10 边扁锥）+ 两颗卵石，落在 |x| 1.00–1.30 带内（允许低于 1.05）
- 顶部：一根漂流木横杆跨满 2.60（两端各比立柱长 0.15）+ 两端绳结；柱顶/下沿各两道麻绳绑扎（0x6B5236）
- 布幡：蓝白相间 5 条（海蓝 0x4FA3C7 / 米白 0xEFE7D6），布面有下垂弧度（中部下垂 0.08），两侧各垂一段布尾；正反面双面建
- 下沿（判定线）：不是硬横梁，而是**两道下垂麻绳**（1.33 / 1.14，垂到最低 1.075）+ 中间吊着 2 片贝壳与 2 根浮木
- 挂件：两侧立柱内侧各挂一个救生圈（橙 0xE8622F + 白箍），圈体 1.52–1.96，底边远高于 1.15
- 自检：800 tris / 包围盒 2.599 × 2.596 × 0.312 / 中央净跨低于 1.05 的三角面 **0**（中央最低点 1.075）/ 低于 1.05 的顶点最小 |x| = 1.010 / 退化三角面 **0** / color+normal 属性齐全

### 沙滩小物件（small-beach.ts）
- 贝壳：6 瓣扇面（正反两面）+ 铰点块，扇面整体抬起 34° —— 平躺的小物件在游戏机位里几乎看不见
- 沙桶：锥形桶身（8 边）+ 桶底圆片 + 桶口箍 + 四段圆弧提手；提手做弧线而不是两根斜棍
- 沙堡：五边下塔（收分）+ 四棱上塔（转 45° 出棱角）+ 压暗的拱门 + 干沙垛口
- 沙滩球：6 瓣 4 色 + 两个极点圆片；球心在半径高处 = 落地状态，不需要额外摆位
- 这四件都**不带接地暗斑**：小物件层由 park.ts 的阴影层统一处理，几何里再加一层会重

## 大背景 backdrop/ 的用法（给 runner-core）

    import { Backdrop } from './backdrop';
    const backdrop = new Backdrop({ side: SEA_SIDE, shoreX: SAND_END });
    scene.add(backdrop.group);
    // 每帧（必须调用，否则穹顶不会跟随玩家）：
    backdrop.update(dt, player.x, player.z);

- 穹顶和云整组跟随玩家 x/z（这条是刚修过的 bug，别改回去：穹顶半径 360 小于相机远平面 420，
  跟随玩家后任何机位都不会被远平面切出三角）
- 穹顶材质写死了 depthWrite=false + depthTest=false + renderOrder=-1000：永远最先画、永远在最后面
- 海面 / 波纹带 / 远岛只跟随 z，水线固定在构造参数 shoreX
- 默认参数已对齐 track.ts：side=1（+x 右侧）、shoreX=9.65（= ROAD_HALF_WIDTH + 0.7 + 5）、水面 y=0.02
- 接线后请把 game.ts 里原来的 createSkyDome()、track.ts 里的海面/波纹带、glow.ts 里的远岛换掉，
  否则会叠两层海、两层云
- 单独几何体也导出了：createSkyDomeGeometry / createCloudGeometry / createSeaGeometry / createWaveBandGeometry / createIslandGeometry

## 给 runner-core 的接口约定（全部 12 件）

- 导出都是 THREE.BufferGeometry 常量，属性只有 position / normal / color，无 uv、无 index
  （例外：**barrierGeometry 是工厂函数**，接线时写 `geometry: barrierGeometry()`，别写成常量）
- 材质：MeshStandardMaterial({ vertexColors: true, roughness: 0.88, metalness: 0 }) 即可；
  不要开 side: DoubleSide——叶面、伞里衬都在几何里做了正反面
- 模型空间：y 向上、原点在地面中心；长椅坐面朝 +z；救生塔楼梯向 +z 伸到 z≈2.6；
  栏杆段沿 x 由 -1.2 到 +1.2（立柱在 x≈-1.15），沿 z 铺时 rotation.y = ±π/2、间距 2.4m
- 顶点色已经烘了「顶亮 / 侧中 / 底暗 + 接地暗部」，setColorAt 建议 0.92–1.08
- 棕榈 / 长椅 / 栏杆段 / 救生塔 的 scale 请保持 1.0；遮阳伞 0.9–1.1 可以
- 5 种障碍物都是正面朝 +z、原点在地面中心，直接替换 obstacles.ts 里 KINDS[kind].geometry 即可，
  碰撞盒的 halfWidth / halfDepth / minY / maxY 一个数不用改
